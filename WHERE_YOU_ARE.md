## 🎯 Next: Add 5 Environment Variables

Think of environment variables like **settings** for your app. They tell your backend:
- What mode to run in (production vs development)
- Security keys to use
- Which database to connect to
- Which websites can access it

---

## 📝 THE 5 VARIABLES YOU NEED TO ADD:

```
1. DEBUG           → Tell Django we're in production mode
2. DJANGO_SECRET_KEY → Security key for Django
3. ALLOWED_HOSTS   → Which domains can host your app
4. CORS_ALLOWED_ORIGINS → Which websites can call your API
5. ANTHROPIC_API_KEY → Your AI chatbot key
```

Plus one more that's **already there**:
```
6. DATABASE_URL    → Auto-added by Railway ✅
```
